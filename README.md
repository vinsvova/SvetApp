# «Будет свет»: Android-приложение

Когда рядом появляется Wi-Fi сеть с заданным именем, приложение:
1. показывает push-уведомление «Да, будет свет в вашем доме» (видно и на экране блокировки);
2. включает экран на 5 секунд;
3. произносит эту фразу голосом (через громкость будильника, поэтому слышно и в беззвучном режиме).

Приложение работает в фоне и при выключенном экране: foreground-сервис + wake lock, скан каждые 30 секунд.
Повторно срабатывает, только если сеть пропадёт (примерно на 1,5 минуты) и снова появится.

## Скачать готовый APK
Готовый APK собирается автоматически при каждом изменении кода: вкладка **Releases** этого репозитория → `SvetApp.apk`.

## Сборка APK вручную
1. Установите **Android Studio** (бесплатно, developer.android.com/studio).
2. File → Open → выберите папку `SvetApp`. Подождите, пока Gradle скачает зависимости.
3. Build → Build App Bundle(s) / APK(s) → **Build APK(s)**.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
4. Перекиньте APK на телефон и установите (разрешите «Установку из неизвестных источников»).
   Или подключите телефон по USB с включённой отладкой и нажмите ▶ Run.

Требования: Android 8.0 и новее.

## Настройка на телефоне
1. Введите имя сети (как оно видно в списке Wi-Fi, регистр не важен) → «Начать слежение».
2. Выдайте разрешения: местоположение, «Устройства поблизости» (Android 13+), уведомления.
3. **Включите геолокацию (GPS)**: без неё Android не показывает приложениям список сетей.
4. Разрешите работу без ограничений батареи.
5. Нажмите «Разрешить автозапуск после перезагрузки» → «Разрешить в любом режиме».
6. Нажмите «Проверить фразу и уведомление».

### Если нет голоса
Настройки → Специальные возможности → Синтез речи → Google: установите русский язык.

### Xiaomi / Huawei / Samsung / Honor
Эти прошивки агрессивно убивают фоновые приложения. Дополнительно:
- **Xiaomi (MIUI/HyperOS):** Настройки → Приложения → Будет свет → Автозапуск: вкл; Контроль активности: «Нет ограничений».
- **Samsung:** Настройки → Батарея → Ограничения фоновой работы → добавьте приложение в «Никогда не переводить в спящий режим».
- **Huawei/Honor:** Батарея → Запуск приложений → Будет свет → управлять вручную, все галочки.
- Закрепите приложение в списке недавних (замок), чтобы его не выгружало.

## Структура
- `WifiWatcherService.kt`: фоновый сервис, сканирование, уведомление, синтез речи
- `MainActivity.kt`: экран настройки и разрешения
- `BootReceiver.kt`: автозапуск после перезагрузки
- `Prefs.kt`: хранение имени сети; здесь же текст фразы (`PHRASE`)
