# «Будет свет»: Android-приложение

Когда рядом появляется Wi-Fi сеть с заданным именем, приложение:
1. показывает push-уведомление «Да, будет свет в вашем доме» (видно и на экране блокировки);
2. включает экран на 5 секунд;
3. проигрывает звук `app/src/main/res/raw/svet_sound.mp3` (через громкость будильника, поэтому слышно и в беззвучном режиме).

Приложение работает в фоне и при выключенном экране: foreground-сервис + wake lock, скан каждые 30 секунд.
Повторно срабатывает, только если сеть пропадёт (примерно на 1,5 минуты) и снова появится.

## Скачать готовый APK
Готовый APK собирается автоматически при каждом изменении кода: вкладка **Releases** этого репозитория → `SvetApp.apk`.

## Сборка APK вручную
1. Установите **Android Studio** (бесплатно, developer.android.com/studio).
2. File → Open → выберите папку `SvetApp`. Подождите, пока Gradle скачает зависимости.
3. Build → Build App Bundle(s) / APK(s) → **Build APK(s)**.
   Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
4. Перекиньте APK на телефон и установите (разрешите «Установку из неизвестных источников»).
   Или подключите телефон по USB с включённой отладкой и нажмите ▶ Run.

Требования: Android 8.0 и новее.

## Настройка на телефоне
1. Введите имя сети (как оно видно в списке Wi-Fi, регистр не важен) → «Начать слежение».
2. Выдайте разрешения: местоположение, «Устройства поблизости» (Android 13+), уведомления.
3. **Включите геолокацию (GPS)**: без неё Android не показывает приложениям список сетей.
4. Разрешите работу без ограничений батареи.
5. Нажмите «Разрешить автозапуск после перезагрузки» → «Разрешить в любом режиме».
6. Нажмите «Проверить звук и уведомление».

### Как заменить звук
Положите свой файл вместо `app/src/main/res/raw/svet_sound.mp3` (имя оставьте тем же) — GitHub соберёт новый APK.

### Huawei / Honor (EMUI, HarmonyOS): обязательно
Эти прошивки усыпляют Wi-Fi и фоновые приложения сильнее всех. Нужно настроить всё:
1. **Запуск приложений:** Настройки → Батарея → Запуск приложений → «Будет свет» → выключить «Управлять автоматически» → включить «Автозапуск», «Косвенный запуск», «Работа в фоне». В приложении есть кнопка, которая открывает этот экран.
2. **Wi-Fi во сне:** Настройки → Wi-Fi → ⋮ → Дополнительные настройки → «Wi-Fi в спящем режиме»: **Всегда**.
3. **Уведомления:** Настройки → Уведомления → «Будет свет» → разрешить, канал «Свет дали»: включить **Баннеры**, **Экран блокировки**, **Приоритет / Не беспокоить: разрешить**.
4. **Батарея:** выключить «Режим энергосбережения»; в «Оптимизации батареи» выбрать «Не разрешать» для приложения.
5. Закрепить приложение в списке недавних (потянуть карточку вниз → замок).
6. Нажать «Тест через 15 секунд», выключить экран и проверить, что экран включается и играет звук.

### Xiaomi / Samsung
- **Xiaomi (MIUI/HyperOS):** Настройки → Приложения → Будет свет → Автозапуск: вкл; Контроль активности: «Нет ограничений»; Другие разрешения → «Экран блокировки» и «Всплывающие окна в фоне»: разрешить.
- **Samsung:** Настройки → Батарея → Ограничения фоновой работы → добавьте приложение в «Никогда не переводить в спящий режим».

### Значок будильника в строке состояния
Пока слежение включено, в строке состояния виден значок будильника. Это нормально: приложение будит планшет раз в минуту через системный будильник, иначе Huawei и другие прошивки полностью усыпляют его при выключенном экране.

### Режим «Чёрный экран» (для Huawei)
EMUI не сканирует Wi-Fi, пока экран выключен. Кнопка «Чёрный экран» держит экран формально включённым: он чёрный, на минимальной яркости, а сканирование работает. Выход — двойное касание. Кнопку питания в этом режиме не нажимайте. Лучше держать планшет на зарядке.

### Как приложение замечает сеть
1. **Подключение (быстро, рекомендуется).** Если планшет хоть раз подключался к нужной сети с паролем, он сам переподключится, когда она появится, и приложение сразу сработает.
2. **Сканирование.** Android разрешает приложениям не больше 4 сканов за 2 минуты, а в фоне порой и меньше. Если в «Параметрах разработчика» есть пункт «Ограничение поиска Wi-Fi» (Wi-Fi scan throttling), его стоит **выключить**.

Оповещение не сработает, если сеть пропала меньше чем на минуту: это считается помехой, а не отключением света.

### Диагностика
Внизу главного экрана видно, когда был последний скан, какие сети видит устройство и было ли оповещение.
Если «Последний список сетей» давно не обновлялся при выключенном экране, прошивка усыпляет приложение: проверьте пункты выше.

## Структура
- `WifiWatcherService.kt`: фоновый сервис, сканирование, уведомление, звук
- `AlarmActivity.kt`: экран оповещения, включается поверх блокировки
- `MainActivity.kt`: экран настройки и разрешения
- `BootReceiver.kt`: автозапуск после перезагрузки
- `Prefs.kt`: хранение имени сети; здесь же текст уведомления (`PHRASE`)
